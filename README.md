# ProyectoBanco-Tarea-1.1-POO-
Proyecto Banco

Simulador de cuentas bancarias en Java para la clase de Programación Orientada a Objetos Practica encapsulamiento y herencia

Clases

CuentaBancaria: clase base Tiene depositar retirar y mostrar datos El saldo es privado.
CuentaAhorro: hereda de CuentaBancaria Cobra comisión de L. 20 después de 3 retiros y calcula interés mensual
CuentaCorriente: hereda de CuentaBancaria Permite sobregiro con cargo del 3% y se puede pagar después
Cómo ejecutarlo

Abrir el proyecto en NetBeans.
si lo tienen en ingles 
Clic derecho en el proyecto y depues darle a Clean and Build.
Clic derecho en el archivo con el main y depues darle a Run File.
